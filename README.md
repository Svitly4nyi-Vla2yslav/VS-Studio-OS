# VS-Studio-OS

Міні-CRM + ERP + AI Business Assistant для VS Web Studio.

## Можливості першого MVP

- CRM-картки клієнтів із статусами, джерелами, нотатками, історією комунікації та наступною дією;
- задачі, документи й фінансові модулі як окремі операційні розділи;
- AI Assistant, який працює через контрольований серверний API, а не напряму з даними браузера;
- зберігання CRM-даних у Firebase.

## Локальний запуск

1. Встановіть залежності:

   ```bash
   npm install
   ```

2. Створіть `.env` у корені. Для AI-помічника потрібен `OPENAI_API_KEY`;
   модель можна перевизначити через `OPENAI_MODEL`, а порт API — через
   `API_PORT` (типово `8787`). Firebase-клієнт читає змінні
   `VITE_FIREBASE_*`, перелічені у `src/firebase.ts`.

3. Запустіть фронтенд і локальний API разом:

   ```bash
   npm run dev
   ```

Скрипт запускає Vite та `server/dev-api.mjs` паралельно. Vite передає
запити `/api` на `http://localhost:8787`.

## Доступні команди

- `npm run dev:vite` — лише Vite;
- `npm run api` — лише локальний AI API;
- `npm run build` — TypeScript-перевірка та production-збірка;
- `npm run preview` — локальний перегляд зібраного застосунку.

## Структура й потік даних

- `src/pages` містить операційні розділи CRM;
- `src/components` — повторно використовувані картки, форми, фільтри та порожні стани;
- `src/utils/*Service.ts` ізолює читання й записи Firebase від UI;
- `server/dev-api.mjs` обробляє локальні запити AI Assistant.

Клієнтські сторінки викликають сервісний шар, а той повертає типи з `src/utils/types.ts`. AI-модуль надсилає запити через `/api`; ключ OpenAI не повинен потрапляти до `VITE_*` змінних або браузерного коду.
